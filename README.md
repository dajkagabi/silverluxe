# SilverLuxe

Ez a projekt egy weboldal front-end részét valósítja meg, amely ezüst ékszerek bemutatására szolgál, különös tekintettel a kézműves mesterségre, a hagyományokra és az egyedi értékekre. A projekt célja, hogy elegáns és felhasználóbarát felületet biztosítson az ezüst ékszerekkel kapcsolatos információk megjelenítéséhez.

## Technológia

* **React:**
* **Tailwind CSS**
* **React-icons**
* **Framer-motion**
* **Lucide-react**



## Telepítés és futtatás

A projekt helyi gépen való futtatásához kövesse az alábbi lépéseket:

1.  **Klónozza a repozitóriumot:**

    ```
    git clone https://github.com/dajkagabi/silverluxe.git

2.  **Lépjen be a projekt könyvtárába:**

    ```
    cd silverluxe
    ```

3.  **Telepítse a függőségeket:**

    ```
    npm install
    # vagy
    yarn install
    ```

4.  **Indítsa el a fejlesztői szervert:**

    ```
    npm start
    # vagy
    yarn start
    ```
